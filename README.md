# addin-www

Marketing site for [A/addin 2.0](https://github.com/tanyewhong-creator/addin) — `addin.tanyewhong.com`.

## stack

Astro 5 · Tailwind v4 · TypeScript · Cloudflare Pages.

## dev

```bash
npm install
npm run dev
```

Visit http://localhost:4321.

## deploy

Pushes to `main` deploy automatically via Cloudflare Pages. See `.github/workflows/deploy.yml`.
